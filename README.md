# Calculadora de IMC

Projeto web responsivo para calcular o Índice de Massa Corporal (IMC) a partir de altura e peso.

## Recursos

- Interface responsiva para computador e celular
- Altura em centímetros e peso em quilogramas
- Suporte a decimal com vírgula ou ponto
- Cálculo do IMC no navegador
- Referência de categorias para adultos de 20 anos ou mais
- Aviso específico para crianças e adolescentes de 2 a 19 anos
- Sem dependências externas
